Instalación para Android TV · versión {{ version }}

Primera instalación

  1. Descargá el APK con el botón de abajo.
  2. Cuando Android lo solicite, permití instalar aplicaciones desde esta fuente.
  3. Aceptá la instalación y abrí Fútbol TV.
  4. La app detectará automáticamente el servidor en la red local.

Descargar APK

Permiso de instalación

Si Android bloquea la instalación, abrí la configuración que aparece en el aviso y habilitá Permitir desde esta fuente para el navegador o explorador de archivos que usaste.

Actualizaciones

  1. La app consulta automáticamente si hay una versión nueva al iniciar.
  2. Si existe, muestra la pantalla de actualización.
  3. Al presionar OK descarga el APK y abre el instalador oficial de Android.
  4. Confirmá la instalación cuando Android lo solicite.

La actualización conserva la configuración de la aplicación.

Si no encuentra el servidor

Verificá que la TV y el servidor estén conectados a la misma red local y que el servidor esté encendido.
